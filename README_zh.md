## 关于 Pasè FX

Pasè FX 是一个社区交易平台，为印尼交易者提供专业工具、高质量教育和市场分析。由来自亚齐的经验丰富的交易者创立，旨在创建健康和可持续的交易生态系统。

> "循序渐进，耐心，不要贪婪"

---

## 主要功能

### AI 交易助手（由 Puter.js 驱动）
- 零成本 AI 分析 — 通过 Puter.js SDK 访问免费 LLM
- 实时市场洞察与技术分析
- 智能交易建议与风险管理提示

### 专业交易工具
- 多时间框架技术分析
- 风险计算器与仓位管理器
- 交易日志与绩效追踪
- 经济日历集成

### 教育中心
- 适合各级别交易者的结构化课程
- 互动学习模块
- 实时网络研讨会录制

## 安装

```bash
git clone https://github.com/mulkymalikuldhrs/pase-fx.git
cd pase-fx
npm install
npm run dev
```

## 项目结构

```
pase-fx/
├── components/     # React 组件
├── pages/          # 页面组件
├── services/       # API 服务
├── hooks/          # 自定义 React Hooks
├── utils/          # 工具函数
├── backend/        # 后端 API
├── constants.ts    # 应用常量
├── App.tsx         # 主应用组件
└── index.tsx       # 入口点
```
